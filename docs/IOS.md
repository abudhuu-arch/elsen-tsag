# iOS апп (Capacitor)

Вэб апп (`index.html`) Capacitor 8-ийн натив бүрхүүл дотор ажиллана. Кодын нэг хувилбар хоёуланд нь хүрнэ.
Вэб хувилбараас ялгаатай нь:

| | Вэб (PWA) | iOS апп |
|---|---|---|
| Сануулга | Апп нээлттэй үед л | **Апп хаалттай үед ч ирнэ** (local notification, сервергүй) |
| Таймер дуусах | Апп нээлттэй үед | Апп хаалттай үед ч мэдэгдэл ирнэ |
| Өгөгдөл | localStorage | localStorage + **Preferences** (iOS UserDefaults, iCloud/компьютерийн нөөцөд ордог) |
| Хоол таб | Claude (claude.ai дотор), эс бол офлайн | Зөвхөн офлайн хөтөлбөр |
| Нөөц хуулбар | Татах / хуваалцах | iOS хуваалцах цонх (Files, AirDrop, Mail) |

## Өгөгдөл хэрхэн хадгалагдах вэ (`native.js`)

- Апп localStorage-ийг өмнөх шигээ ашиглана. `elsen_*` түлхүүр бүрийн бичилт **Preferences руу давхар бичигдэнэ**.
- **Анх нээхэд** localStorage-д байгаа бүх `elsen_*` түлхүүр Preferences руу хуулагдана. localStorage-ээс юу ч устахгүй.
- **iOS вэб санг цэвэрлэсэн бол** (сул зай багатай үед ингэж болно) бүх өгөгдөл Preferences-ээс буцаж хуулагдаад апп нэг удаа дахин ачаална.
- Вэб хувилбар (Safari) ба iOS апп **өөр өөр сантай**. Вэбээс шилжих бол: вэб дээр *Тохиргоо → Нөөц хуулбар хадгалах*, дараа нь апп дээр *Тохиргоо → Нөөцөөс сэргээх*.

## 1. Нэг удаагийн бэлтгэл

1. App Store-оос **Xcode** суулгана (үнэгүй, ~10 ГБ). Нэг удаа нээж, лицензийг зөвшөөрнө.
2. *Xcode → Settings → Components* хэсгээс **iOS Simulator**-ыг татна.
3. Terminal дээр Xcode-ыг идэвхжүүлнэ. Одоо зөвхөн Command Line Tools идэвхтэй байгаа тул энэ алхам заавал хэрэгтэй:
   ```sh
   sudo xcode-select -s /Applications/Xcode.app/Contents/Developer
   ```
4. Төслийн хамаарлуудыг суулгана:
   ```sh
   cd ~/elsen-tsag
   npm install
   ```

## 2. Симулятор дээр ажиллуулах

```sh
npm run ios        # www/ бэлдэх → ios/ руу хуулах → Xcode нээх
```

Xcode дээр:
1. Анх нээхэд Swift Package-ууд татагдана (баруун дээд буланд «Resolving packages», 1–2 минут).
2. Дээд мөрөнд scheme **App**-ыг сонгоод төхөөрөмжөөр **iPhone 16** (эсвэл дурын iPhone симулятор) сонгоно.
3. **▶** (⌘R) дарна. Симулятор нээгдэж апп эхэлнэ.

Симуляторт *Signing* шаардлагагүй. Жинхэнэ iPhone дээр туршихын тулд *App → Signing & Capabilities → Team* хэсэгт Apple ID-гаа нэмнэ.

`index.html`, `i18n.js`, `native.js`-ийг өөрчилсний дараа `npm run sync` ажиллуулаад Xcode дээр ▶-ыг дахин дарна.

## 3. Юуг шалгах вэ

**Эхлэх заавар ба хэл**
- Анх нээхэд эхлэх заавар (4 дэлгэц) гарна. Хэл нь симуляторын хэлээр (*Settings → General → Language*) сонгогдоно: mn, en эсвэл cs; бусад хэл бол en.

**Апп хаалттай үеийн сануулга**
1. *Тохиргоо → Мэдэгдэл зөвшөөрөх* → **Allow**. Тэмдэглэл: «Сануулга апп хаалттай үед ч ирнэ».
2. *Мэдэгдэл туршиж үзэх* дарж **⇧⌘H** (Home) дарна. 5 секундын дараа баннер гарна.
3. Нэг дадалд одоогоос 2 минутын дараах сануулгын цаг тавиад хадгална. Home дарж аппаа бүр хаана (⇧⌘H хоёр удаа → аппыг дээш шударна). Тэр цагт баннер гарна.
4. Минуттай дадлын таймерыг (▶) эхлүүлээд Home дарна. Таймер дуусахад «Хугацаа дууслаа» мэдэгдэл ирнэ.
5. Дадлаа өнөөдөр тэмдэглэвэл тухайн өдрийн сануулга нь цуцлагдана. Долоо хоногийн тодорхой өдрүүдэд хийдэг дадлын сануулга зөвхөн тэр өдрүүдэд ирнэ.

**Өгөгдөл**
1. Хэдэн дадал тэмдэглээд аппыг бүр хааж дахин нээнэ. Бүгд хэвээр байна.
2. iOS вэб санг цэвэрлэх үеийг дуурайх: Mac-ийн Safari → *Develop → Simulator → localhost* → Console дээр:
   ```js
   localStorage.clear(); location.reload()
   ```
   Апп өгөгдлөө Preferences-ээс сэргээж, эхлэх заавар гарахгүй, дадал болон түүх бүгд буцаж ирнэ.
   (*Develop* цэс харагдахгүй бол: Safari → Settings → Advanced → «Show features for web developers».)

**Хоол таб**
- «Хөтөлбөр гаргах» → «Апп дотор бэлдсэн (офлайн)». Claude-ийн тухай юу ч харагдахгүй. Доор нь «эмнэлгийн зөвлөгөө биш» гэсэн анхааруулга бий.

**Нөөц хуулбар**
- *Тохиргоо → Нөөц хуулбар хадгалах* → хуваалцах цонх → *Save to Files*.
- Вэбээс авсан `.json` файлыг симулятор руу чирж оруулбал Files апп дотор хадгалагдана. Дараа нь *Нөөцөөс сэргээх*-ээр сонгоно.

## 4. Асуудал гарвал

| Алдаа | Шийдэл |
|---|---|
| `xcode-select: error: tool 'xcodebuild' requires Xcode` | Дээрх 1.3 алхам |
| `No such module 'Capacitor'` | *File → Packages → Reset Package Caches*, дараа нь ▶ |
| Апп хоосон хар дэлгэцтэй | `npm run sync`-ийг ажиллуулаагүй байна (`ios/App/App/public` хоосон) |
| Мэдэгдэл ирэхгүй | Симуляторын *Settings → Notifications → Элсэн цаг* хэсэгт зөвшөөрөл асаалттай эсэхийг шалгана. Апп дэлгэц дээр нээлттэй байхад мэдэгдэл баннер хэлбэрээр гарна |

## Тохиргоо

- Bundle ID: `mn.elsentsag.app` (`capacitor.config.json` ба Xcode-д). App Store Connect-д бүртгэхээс өмнө өөрийнхөөрөө сольж болно.
- Зөвхөн iPhone, босоо дэлгэц. `ITSAppUsesNonExemptEncryption = NO`. Хэлүүд: mn, en, cs.
- Icon (1024×1024, тунгалаг хэсэггүй) ба нээх дэлгэц `ios/App/App/Assets.xcassets`-д бий.
