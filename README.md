# Элсэн цаг

Утсан дээр апп шиг суулгадаг, интернэтгүй ажилладаг өдрийн төлөвлөгч (PWA).
Энгийн HTML + CSS + JavaScript, framework болон сан байхгүй. Бүх өгөгдөл утасны `localStorage`-д хадгалагдана.

## Боломжууд
**Өдөр**
- Өдрийн турш урсдаг элсэн цаг: тасралтгүй унах элсний ширхэг, минутад нэг эргэх секундын цагираг, секундтэй цаг,
  шинэ өдөр эхлэхэд эргэх анимэйшн, сонголтоор элс урсах намуухан дуу. Зун/өвлийн цагийн шилжилтэд (23/25 цагийн өдөр) зөв тооцно
- «Одоо / Дараа нь» (блок дуусах хүртэлх явцын шугамтай), 24 цагийн шугам (унтах, ажил, чөлөөт цаг, сануулгын цэг)
- **Ээлжийн хуваарь**: ээлж бүрийн нэр, ажил/унтах цаг, хэдэн хоногоор солигдох, одоо аль ээлж явааг тохиргоонд оруулна. Цаг нь автоматаар солигдоно
- **Дадал бүрийн дараалал** («🔥 12 дахь өдөр») ба **давтамж**: өдөр бүр / 7 хоногт N удаа / сонгосон гарагууд. Хийх өдөр биш өдөр дарааллыг таслахгүй, өдрийн тоололд орохгүй (хийвэл нэмэлтээр тоологдоно)
- **66 хоногийн зам** дадал бүрт, **амрах өдөр** сард 2 удаа: «☾ Амрах» товчоор, эсвэл мартсан өдрийг автоматаар нөхнө. Дараалал тасрахгүй
- Заавал хийх зүйлс: дарж тэмдэглэнэ, даалгавар бүр **таймер** (▶/⏸/↺), **сануулга**, **тоо бүртгэл** (км, хуудас, удаа) -тай
- **Ус** уух тоологч, **нойрны бүртгэл** (7 хоногийн дундаж), орой **өдрийн тойм** (1–5 үнэлгээ, нэг мөр тэмдэглэл)
- **7 хоногийн тайлан** ням гарагт: биелэлт %, хамгийн сайн өдөр, сул даалгавар, нийлбэрүүд
- Сүүлийн 7 хоног ба дараалсан өдрийн тоо. Өдөр дээр дарахад тухайн өдрийн дэлгэрэнгүй нээгдэнэ
- Бүгдийг хийхэд баярын дуу, чичиргээ

**Секундомер**: тойрог тоолно. Хугацааг сонгосон даалгаварт бүртгэнэ

**Хоол & Фитнес**: гэрийн хүнс, 7 хоногийн хоол ба дасгалын хөтөлбөр.
claude.ai дотор `claude.use("sample")`-ээр Claude гаргана, бусад үед (PWA, офлайн) апп доторх `fallbackPlan()` ажиллана

**Статистик**: сарын календарь, бүрэн өдөр, дундаж биелэлт (өмнөх сартай харьцуулсан), зарцуулсан цаг,
хамгийн урт дараалал, хамгийн сайн / сул гариг, 7 хоногийн тайлан (өмнөх 7 хоногуудыг үзэх), нойр, ус, үнэлгээний дундаж,
даалгавар тус бүрийн биелэлт ба тооны нийлбэр

**Тохиргоо**: цагийн хуваарь, даалгавар (нэр, таймер, сануулга, дараалал), мэдэгдэл, дуу,
нөөц хуулбар хадгалах / сэргээх (файл эсвэл **Хуулах / Буулгах**), апп суулгах

## Ажиллуулах / нийтлэх
Service worker зөвхөн `https://` эсвэл `localhost` дээр ажиллана.

```sh
python3 -m http.server 8000   # http://localhost:8000
```

Утсанд суулгахын тулд HTTPS хостинг дээр тавина (GitHub Pages, Netlify, Cloudflare Pages г.м.).
Бүх зам харьцангуй тул дэд хавтсанд (`/elsen-tsag/`) байрлуулсан ч ажиллана.

- **Android (Chrome)**: Тохиргоо → «Нүүр дэлгэцэнд суулгах». Icon-ыг удаан дарахад Секундомер, Статистик руу шууд орно
- **iPhone (Safari)**: Хуваалцах → «Нүүр дэлгэцэнд нэмэх». Мэдэгдэл авахад iOS 16.4+ хэрэгтэй, зөвхөн суулгасан апп дээр ажиллана.
  Суулгаагүй үед Safari 7 хоног нээгээгүй сайтын өгөгдлийг устгаж болзошгүй тул заавал суулгана
- Messenger / Facebook / Instagram доторх хөтчөөс суулгах боломжгүй: апп энэ тохиолдлыг таньж, Safari/Chrome-оор нээхийг зааварлана

**Утсанд зориулсан зүйлс**
- Android: «Буцах» товч Тохиргоог хааж, бусад табаас Өдөр рүү буцна. Мэдэгдлийн цагаан badge icon, чичиргээ
- iPhone: нээх үеийн ачаалах дэлгэц (`splash/`, 11 загварын iPhone), оролтын талбар 16px тул дарахад дэлгэц томрохгүй,
  сануулгын цагийг арилгах «×» товч, iOS 18+ дээр хөнгөн чичиргээ (haptic)
- Хоёуланд: гар нээгдэхэд доод цэс нуугдана, Тохиргоо нээлттэй үед ар талын хуудас гүйхгүй, pull-to-refresh-ээр санамсаргүй дахин ачаалахгүй,
  notch/Dynamic Island-ын зай, хоёр дарахад томрохгүй

`index.html` нь ганцаараа ч ажиллана (жишээ нь claude.ai artifact). Тэр үед шрифт Google Fonts-оос ачаалагдана, PWA боломжууд идэвхгүй байна.

## Шинэ хувилбар гаргах
`index.html`-ийг өөрчлөхөд өөр юу ч хийх шаардлагагүй, учир нь хуудас эхлээд сүлжээнээс уншина.
Кэшлэгдсэн бусад файлыг (icon, шрифт, manifest) өөрчилбөл `sw.js` дахь `VERSION`-ийг нэмэгдүүлнэ.
Хэрэглэгчид «Шинэ хувилбар бэлэн боллоо → Шинэчлэх» гэсэн мэдэгдэл харагдана.

## Тест
Тест нь зөвхөн хөгжүүлэлтэд зориулсан бөгөөд жинхэнэ Chromium дээр ажиллана:

```sh
cd tests
npm install
npm run setup      # Chromium татна (нэг удаа)
npm test
```

Тестүүд дараах зүйлсийг шалгана: файлын бүтэц, хуучин болон гэмтсэн өгөгдлийг шилжүүлэх/засах, даалгавар тэмдэглэх (гарын товчоор ч),
таймер (шөнө дундыг давах үед ч), сануулга, секундомер, хоолны хөтөлбөр (офлайн ба Claude), нөөц хадгалах/сэргээх/буцаах,
статистик, офлайн горим, утсан дээрх «Буцах» товч, оролт, гар, зун/өвлийн цагийн шилжилт, ээлж, ус, тоо бүртгэл,
оройн тойм, нойр, 7 хоногийн тайлан, хуулах/буулгах нөөц.

## Хязгаарлалт
Сервер байхгүй тул **сануулга зөвхөн апп нээлттэй үед ажиллана**. Апп хаалттай үед өнгөрсөн сануулга дараа нээхэд улаанаар тэмдэглэгдэнэ.
Таймер явж байхад дэлгэц унтрахгүй (Wake Lock), тиймээс таймер дуусах мэдэгдэл найдвартай ирнэ.

Өгөгдөл зөвхөн тухайн төхөөрөмжид хадгалагдана. Утас солихоос өмнө **Тохиргоо → Нөөц хуулбар хадгалах**-ыг ашиглана уу.

## Файлууд
| Файл | Агуулга |
|---|---|
| `index.html` | Апп бүхэлдээ (HTML, CSS, JS) |
| `sw.js` | Service worker: офлайн кэш, мэдэгдэл дээр дарахад апп нээх |
| `manifest.json` | PWA тохиргоо, icon, товчлол, дэлгэцийн зураг |
| `icons/`, `fonts/`, `screenshots/` | Icon, шрифт (Cormorant Garamond, Manrope, OFL лиценз), суулгах цонхны зураг |
| `splash/` | iPhone-ийн нээх үеийн дэлгэц |
| `tests/` | Автомат тест (зөвхөн хөгжүүлэлтэд) |

## localStorage түлхүүрүүд
Хуучин өгөгдлийг хэзээ ч устгахгүй: формат өөрчлөгдөхөд зөвхөн шинэ талбар нэмэгдэнэ, апп танихгүй талбарыг ч хадгалж үлдээнэ.

| Түлхүүр | Агуулга |
|---|---|
| `elsen_cfg` | Цагийн хуваарь, ээлж `shifts`, дадлууд `tasks`, устгасан дадлууд `archive` (түүхтэйгээ үлдэнэ), `sound`, `sandSound`, `waterGoal`, формат `v` |
| `elsen_hist` | `{өдөр: {даалгавар: "HH:MM"}}`: биелсэн цаг (бүтэц анхныхаараа) |
| `elsen_tm` | `{өдөр: {даалгавар: {acc, run, base}}}`: таймер/секундомерын зарцуулсан хугацаа |
| `elsen_snap` | `{өдөр: [даалгаврын id]}`: тухайн өдрийн жагсаалт (статистикт) |
| `elsen_sw` | Секундомерын төлөв |
| `elsen_notified`, `elsen_notif_asked` | Өнөөдөр илгээсэн сануулга, зөвшөөрөл асуусан эсэх |
| `elsen_pantry`, `elsen_foodcfg`, `elsen_plan` | Хоол & Фитнес |
| `elsen_water`, `elsen_qty` | `{өдөр: аяга}`, `{өдөр: {даалгавар: тоо}}` |
| `elsen_rest` | `{өдөр: [дадлын id]}`: өөрөө сонгосон амралтын өдөр |
| `elsen_review`, `elsen_sleep` | `{өдөр: {r: 1–5, n: тэмдэглэл}}`, `{өдөр: {s: унтсан, w: боссон}}` (боссон өдрөөр) |
| `elsen_backup_at`, `elsen_undo` | Сүүлд нөөцөлсөн огноо, сэргээхийн өмнөх өгөгдөл («Буцаах»-д) |
| `elsen_premig_v1` | Формат шинэчлэхийн өмнөх бүх өгөгдлийн хөндөгдөөгүй хуулбар. Апп үүнийг хэзээ ч устгахгүй |

## 7 хоногийн автомат сайжруулалт (зөвхөн энэ Mac дээр)
Лхагва гараг бүр 03:00-аас (апп бүр өөр шөнө; компьютер унтарсан байсан бол дараагийн асалтад) Claude Code аппыг шалгаж
1–3 жижиг сайжруулалт хийнэ: **`auto-improve` салбар** дээр, тусдаа хавтсанд (`../elsen-tsag-auto`, git worktree).
Тест (`npm --prefix tests test`) давсан үед л commit хийнэ, унасан бол `git stash`-д хадгална.
**main-д нийлүүлэхгүй, GitHub руу push хийхгүй** — та шийднэ. Тайлан `logs/`-д (git-д ордоггүй), утсанд ntfy-ээр 3 мөр тойм
(сэдэв `~/projects/.env`-ийн `NTFY_TOPIC`).

```sh
bash scripts/auto/launchd.sh install   # суулгах (status | stop | start)
FORCE=1 bash scripts/auto/run.sh        # одоо ажиллуулах
```
